# Global COVID-19 Data Analysis & Visualization

## 📌 Project Overview
This project focuses on the deep-dive exploration of global COVID-19 datasets using **PostgreSQL**. The goal was to transform raw data into a structured format suitable for high-level executive reporting in Tableau, specifically focusing on mortality counts and population infection density.

## 🛠️ Tech Stack
* **Database:** PostgreSQL (Data cleaning, Type conversion, and Aggregation)
* **Visualization:** Tableau
* **Data Source:** Our World in Data (Global COVID-19 Dataset)

## 📂 Project Structure
* **`Tableau SQL Queries.sql`**: Optimized PostgreSQL scripts used to feed the visualization layers.
* **`Data Exploration.sql`**: Raw exploratory queries used to identify trends and outliers.
* **`Covid Dashboard.pdf`**: Final dashboard output.

## 📊 Tableau Insights
The project culminates in a dashboard focusing on:
1. **Total Deaths per Country:** A global ranking of cumulative mortality rates.
2. **Percent Population Infected per Continent:** A regional density analysis showing the virus's reach relative to population size.
